# Libasunnoor (لباس النور)

**Garments of Light — Heritage Thobes, Jubbas & Islamic Menswear E-Commerce Store**

Libasunnoor is a modern, responsive e-commerce storefront crafted in a **Classic Heritage (Emerald, Warm Sand & Champagne Gold)** aesthetic, built specifically for seamless **Order via WhatsApp** concierge commerce.

## Key Features

- **Curated Heritage Catalog:** Signature Emirati & Saudi Thobes, Gold-Zari Embroidered Jubbas, Linen-Cotton Kurta Sets, Ceremonial Bishts, Handcrafted Omani Kumas/Kufis, Pure Alcohol-Free Cambodi Oud Attar, and Velvet Mihrab Sajjada Sets.
- **Seamless WhatsApp Ordering:**
  - **Shopping Bag & Itemized Checkout:** Add multiple items with selected lengths/shades/notes, enter delivery & payment preferences, and launch a pre-formatted WhatsApp order message in one tap.
  - **Instant 1-Tap Product Order:** Direct WhatsApp checkout from any product card or quick-view modal.
  - **Copy Order Summary:** Fallback one-click copy of the formatted order text.
- **Interactive Thobe Size & Length Calculator:** Height-to-Gulf-length (52"–62") finder plus reference measurement chart.
- **Bespoke Tailoring Atelier:** Dedicated custom measurement form for Nikah grooms, family Eid sets, and Sunnah above-ankle alterations sent directly to the master tailor on WhatsApp.
- **Multi-Currency Display:** Switch effortlessly between `INR (₹)`, `AED`, and `SAR`.

## Getting Started

```bash
npm install
npm run dev
```

## Customizing Your Store WhatsApp Number

Update `STORE_CONFIG` inside [`src/data/products.ts`](src/data/products.ts) with your store's WhatsApp phone number (currently configured as `918086710179`), address, and contact details.

## Production Build

```bash
npm run build
```
